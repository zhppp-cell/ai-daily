# AI 日报

每天汇总 AI 领域值得看的动态：模型与产品、工具与开源、论文速览、行业与融资。

- 网站：https://zhppp-cell.github.io/ai-daily/
- 每日数据：`数据/YYYY-MM-DD.json`
- 首页 `index.html` 内含当天数据，可以直接双击本地打开，也能在网站上访问

## 更新方式

由 Codex 每天抓取公开新闻源，整理成中文摘要，重新生成 `index.html` 并提交推送。

## 数据源

Hacker News、TechCrunch（AI 频道）、arXiv cs.AI、GitHub Trending、The Verge、Ars Technica、MarkTechPost、Anthropic News
